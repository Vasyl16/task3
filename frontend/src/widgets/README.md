# widgets/

Large, self-contained UI blocks composed from features/entities/shared.

| Slice | What it is |
| --- | --- |
| `app-layout/` | header, nav, the realtime connection banner, route `<Outlet/>` shell |
| `product-card/` | catalog grid card (search result → link to product detail) |
| `search-filters/` | the catalog's filter bar (category, price, rating, stock, sort) |
